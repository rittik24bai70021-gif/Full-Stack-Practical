# Backend — Spring Boot / Java 17+
Rittik Basak · 24BAI70021

Run `java -jar dist/canarydock.jar` for the provided build, or `.\mvnw.cmd spring-boot:run` from this directory for source development on Windows.

API: http://localhost:8080/api/info. Health: http://localhost:8080/actuator/health.

This local backend has no frontend homepage. Start the frontend separately and browse http://localhost:3000.

Java source: src/main/java/com/rittik/canarydock/. Configuration: src/main/resources/application.properties. Tests: src/test/java/.
