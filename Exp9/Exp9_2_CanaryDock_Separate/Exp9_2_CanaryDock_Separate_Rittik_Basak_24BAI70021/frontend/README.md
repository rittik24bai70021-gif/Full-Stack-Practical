# Frontend — HTML, CSS, JavaScript / Node.js 18+
Rittik Basak · 24BAI70021

Run `node server.cjs` from this directory. Open http://localhost:3000. No npm install is required.

Start the Spring Boot backend separately on port 8080. The Node server proxies API requests to it. Use the provided server instead of Live Server.

Edit public/index.html for layout, public/styles.css for appearance, and public/app.js for browser interactions. Refresh the browser after changing these files.
